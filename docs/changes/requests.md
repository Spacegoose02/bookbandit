# Requests, downloads, uploads, job runner (`ws/requests`)

- 2026-11-14: Generic job runner on the `jobs` table (retries with backoff, deferral for polling, cancel, per-job logs, admin status API at `/api/admin/jobs`). Book requests: anyone asks, a kid's request above their rating is declined on the spot from the server's own lookup, a linked parent or admin approves. Approved requests download through Shelfmark, or sabnzbd with a Newznab indexer, into `BOOKS_DIR/_incoming/` and a library scan puts them in the admin inbox. Admin direct-URL downloads, browser uploads (admins, adults when allowed). Web: `/requests` (ask, my requests, to approve, downloads, upload, downloader settings) and a kid "Wish for a new book" page. Migration `0004_requests_jobs`.
