# Admin and family UI changes (`ws/admin`)

- 2026-11-15: Book editor. Admins get a round pencil on every book cover (on hover) and an **Edit** button on the book page, opening a dialog with Details (title, sort title, original title, subtitle, authors, series and number, year, publisher, age group, description), Tags (fiction / nonfiction and categories), Artwork (the librarian cover picker) and Advanced (ISBN, language, pages, provider ids). Each field has a lock; editing locks it, and locked fields survive metadata refresh, Calibre imports and the auto-categorizer. Category pages get **Select books** to move, add or remove books in bulk (their categories get locked). Librarian bulk edits and cover changes lock what they set. Migration `0016_book_locks` (`books.original_title`, `books.locked_fields`) (this PR)
- 2026-11-14: Family dashboard shows reading time from `GET /api/reading/stats`: minutes per day for the last 7 days (reading and listening), streak, daily average and the books with the most time; each kid card shows minutes this week (this PR)
- 2026-11-14: Admin and family UI: `/admin` (overview + scan, inbox with bulk approve, rating, metadata edit, merge, reject; needs-a-rating queue; people, kids and paired devices; Audiobookshelf, SMTP and metadata-lookup settings) and `/family` (per-kid reading, requests and read-only Barnaby chats). New APIs in `routes/admin-library.ts`, `admin-settings.ts`, `admin-family.ts`; see [admin-api.md](../admin-api.md). Metadata API keys can be set in the browser and apply without a restart (#15)
