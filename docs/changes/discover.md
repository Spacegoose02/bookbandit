# Discover changes (`ws/discover`)

- 2026-11-15: Novels no longer pile up in **Nonfiction**. A book no genre rule placed was guessed "Nonfiction" unless a subject said "fiction", and "Fiction" was never saved as a subject, so re-filing from saved subjects (the start-up tidy, Rebuild) sent novels there. Now only subjects that say nonfiction ("Nonfiction", "Juvenile literature", "Handbooks") lead to Nonfiction, anything else unplaced is Fiction, comics count as fiction, "Fiction"/"Nonfiction" are kept as subjects, and Children's Books / Young Adult sit next to Fiction or Nonfiction instead of replacing it. Existing libraries re-file their Fiction/Nonfiction books once on start (taxonomy v2), and Rebuild does the same. No migration (this PR)
- 2026-11-14: Richer Discover. Personal rows ("Next in your series", with Hardcover filling in books the library lacks; "Because you read X" from Barnaby's more-like-this and meaning search; "More by" your authors), Open Library genre rows matching the curated categories, "New and noteworthy" in place of the near-duplicate yearly list, hand-picked prize winners (kids' prizes rated, so kids see the ones meant for them), library-only genre rows for kids, English editions and covers, and no book repeated across rows. Sections with a jump bar. No migration (this PR)
- 2026-11-14: Curated categories. Raw metadata subjects are kept as search-only `subject` tags and books are filed under a short curated list (Fantasy, Mystery & Crime, Biography & Memoir …); near-duplicates merged, small categories hidden, and a new **Admin → Categories** page to rename, merge, hide, promote and re-file. Existing libraries are tidied once on start without dropping book links. Migration `0015_categories` (this PR)
- 2026-11-14: "Request it" on Discover understands `409 already_in_library` from `POST /api/requests` and links to the book instead of showing an error (this PR)
- 2026-11-14: Discover (Open Library and Hardcover trending with In library / On Kindle / Request it badges, Popular in your family), series pages in reading order with admin create/rename/drag-to-reorder, category browsing, Cook mode for cookbooks, Kindle library CSV import as metadata-only books. All through the content lock; kids only see outside books already on their shelf. API: [discover-api.md](../discover-api.md) (#16)
