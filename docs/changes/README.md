# Change logs, one file per workstream

Each workstream appends to its own file here instead of a shared table, so parallel PRs don't
conflict. Newest entry at the top. Only edit your own workstream's file; the lead edits `lead.md`.

Entry format, one bullet per PR:

```
- 2026-11-14: What changed, in a sentence or two, with links to any new docs (#PR)
```

If you don't know the PR number yet, write `(this PR)` and fix it in a follow-up. A workstream
without a file creates one named after its branch suffix (for example `ws/listen` → `listen.md`).
