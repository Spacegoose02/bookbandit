# Barnaby AI (`ws/ai`) change log

- 2026-11-14: One review flow for new and unrated books. Books Barnaby has rated leave the Inbox by themselves (setting, on by default; likely copies stay; unrated still means adult-only), including ones rated before this change. The Inbox shows his rating (outlined ✨, with how sure he is and why) and metadata fixes on each book, with filters, **Approve with Barnaby's picks**, **Ask Barnaby** and **Show more** (it only ever showed the first 50). **Needs a rating** now also lists books whose looser Barnaby rating waits for a yes, with **Accept Barnaby's picks**; the Barnaby settings page links there instead of keeping its own list. Optional **Trust ratings Barnaby is sure about** (off). Rating a book any way settles his suggestion. The Inbox text no longer says Barnaby guessed the rating shown. No migration (this PR)
- 2026-11-14: Provider **Test** works for embeddings models (Ollama `nomic-embed-text`): it embeds a short text instead of chatting when the model looks like an embeddings model or is only used for meaning search, and falls back to embeddings when the server refuses the chat. Claude can no longer be picked for meaning search (no embeddings API); older saves that picked it read as off (#41)
- 2026-11-14: Rating helper and metadata cleanup show how far through the library they are, how many suggestions wait for review (with a link), an "All done" state, and books that failed (skipped by later batches, **Try them again**). New **all that's left in the background** and **Stop**. Cost estimates per book, per batch and for the rest, plus spend so far; local servers are free, cloud prices come from a built-in list or a per-provider **Price**. No migration (this PR)
- 2026-11-14: Barnaby round 2. "More like this" on every book page (works with no AI; kids stay inside their rating), meaning search with embeddings merged into library search, "Find a book" smart requests (`/barnaby/find`, age cap and "for <kid>"), streaming chat replies for grown-ups (`POST /api/ai/chat/stream`), metadata cleanup with per-field accept, and the rating helper moved onto the job runner. Migration `0009_ai_round2` (new tables only). See [ai.md](../ai.md) (this PR)
- 2026-11-14: Claude provider no longer sends `temperature`, which current Claude models (e.g. `claude-opus-5-5`) reject with HTTP 400 (this PR)
- 2026-11-14: Barnaby AI and Barnaby chats tabs in the Admin and Family areas, so the settings and the kids' chat log are reachable from the menus (#29)
- 2026-11-14: Barnaby AI. Providers (Ollama/LM Studio/llama.cpp/OpenAI-compatible, Anthropic, Gemini) chosen per feature, SearXNG web search with sources, moderation (word filter + Llama Guard or any model), grown-up chat, kid mode (parent switch, no chat under 5, daily limit, content lock, personal details removed, parent log), spoiler-free book chat, rating helper, usage log. Web: floating Barnaby button, `/barnaby`, `/barnaby/family`, `/barnaby/settings`. Setup: [ai.md](../ai.md) (#22)
